# Security

Please report a vulnerability privately, through GitHub's "Report a vulnerability" button on
this repository's Security tab, rather than in a public issue. Include what you found, how to
reproduce it and which version or commit you tested.

You will get an answer within a week. Fixes go to the latest release; older releases are not
patched.

In scope: the telnet and admin listeners, authentication and sessions, the admin API, the
importer's handling of untrusted files, and the release images. Out of scope: weaknesses of the
original game's rules that the server reproduces on purpose (`docs/differences.md`).
